# Paradise Nursery

Paradise Nursery is a React plant shop application where users can browse indoor plants, add plants to a shopping cart, change quantities, remove items, and view the total price.

## Features

- Landing page with company name and Get Started button
- About Us page with company information
- Product listing page with plant categories
- Add to Cart functionality
- Shopping cart with quantity controls
- Remove items from cart
- Total item count and total price
- Responsive design

## Technologies

- React
- Vite
- Redux Toolkit
- React Redux
- React Router

## Run the project

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite in the terminal.
